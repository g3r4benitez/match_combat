## Summary

Add the sponsors banner image (`static/images/sponsors.png`) to the footer of every entrada PDF generated by `EntradaPdfService`. The image is placed at the bottom of the page, the QR code shifts upward to make room, and the system degrades gracefully if the image file is missing.

## Implementation Details

### Layout Calculations

```
Page: 5cm wide × 10cm tall, margin 0.3cm
Content width: 4.4cm

Sponsors image (727×253px):
  - Scaled width: 4.4cm (CONTENT_WIDTH)
  - Scaled height: 4.4 × (253/727) ≈ 1.53cm
  - Position: x = MARGIN (0.3cm), y = MARGIN (0.3cm) — anchored to bottom

QR code (3.5cm × 3.5cm):
  - Previous y: MARGIN + 0.3cm = 0.6cm
  - New y: MARGIN + sponsors_height + 0.2cm gap ≈ 2.03cm
  - Centered horizontally (unchanged)

Vertical space check:
  - Text content ends at: ~6.4cm from bottom
  - QR top: 2.03 + 3.5 = 5.53cm from bottom
  - Gap: 0.87cm ✓ sufficient
```

### Changes to `EntradaPdfService.generate_pdf()`

1. **Import** `pathlib.Path` and `logging` at module level
2. **Add constant** `SPONSORS_IMAGE_PATH` using `ROOT_DIR` from config
3. **Add private method** `_draw_sponsors_footer(self, c: canvas.Canvas) -> float`:
   - Attempts to load the sponsors image
   - Scales proportionally to `CONTENT_WIDTH`
   - Draws at bottom of page (y = MARGIN)
   - Returns the height used (or 0 if image not found)
   - Wraps in try/except for graceful degradation
4. **Modify QR positioning** in `generate_pdf()`:
   - Call `_draw_sponsors_footer()` before drawing QR
   - Use the returned height to offset `qr_y` upward

### Error Handling

- `FileNotFoundError` or any image loading error: log warning, return height 0
- PDF generation continues normally without the sponsors image
